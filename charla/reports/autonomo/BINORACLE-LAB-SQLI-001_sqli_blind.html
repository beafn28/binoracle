Descripción Técnica

Descripción Oficial NVD

Escenario de laboratorio de demostración: SQL injection time-based blind en una aplicación Python Flask con backend MySQL. El endpoint /search acepta el parámetro 'q' que se inserta directamente en la consulta SQL sin sanitización mediante interpolación de cadenas (f-string). Un atacante puede inyectar comandos SQL vía el parámetro q; la inyección time-based blind es posible con MySQL SLEEP(): q=1' OR (SELECT 1 FROM (SELECT SLEEP(4)) t)-- - provoca un retraso de 4 segundos. No se requiere autenticación. Demuestra la capacidad de binoracle para detectar y verificar esta clase de vulnerabilidad de forma completamente autónoma.

Estrategia de Explotación (hipótesis LLM)

Exploit the time-based blind SQL injection vulnerability by injecting a payload that causes the server to delay for a specific amount of time. This can be used to determine if the injected SQL command is executed successfully.

Funciones Vulnerables

  • SELECT * FROM products WHERE name = '<user_input>'
