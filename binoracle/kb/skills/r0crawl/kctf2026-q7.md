# Summary of the Challenge

The target is a deterministic encryption program named HexMaze. The plaintext is processed as ASCII bytes, and the algorithm includes byte encoding, hexadecimal bit operations, modulo 16 cyclic shifts, fixed position reordering, and fixed digest perturbation. All samples and FLAGs use the key `121`.

## Verifiable Constants

- Key: `121`
- Known Samples:
  - `TLU` → `94AA48550495`
  - `Hello` → `34BB405504B5223594B94C53`
  - `2026` → `A4884455048522332235A483`
  - `abcd!` → `547B475584B5223564BB4553`

- Final FLAG: `flag{T1u_2026_Kc7f_Crypt0_M4ster!}`

## Standard Solution Workflow

1. **Observe the Structure of Encrypted Text**
   - Encrypted text is output in groups of 6 bytes.
   - Each group corresponds to one 6-byte block, with 3 bytes of plaintext.
   - If a group has fewer than 3 bytes at its end, it is padded to complete the 6-byte block.
   - The structure of each full block: `[a,4] [b,c] [4,d] [5,5] [e,4] [f,5]`, with valid half-bytes being `a b c d e f`.

2. **Determine the Length of FLAG**
   - Encrypted FLAG is 144 hex characters = 72 bytes = 12 blocks.
   - The last block has a structure `22 33 22 35 ?4 ?3` which matches the tail block with one remaining byte.
   - Therefore, `len(flag) mod 3 = 1`, total length is `11 * 3 + 1 = 34` bytes.

3. **Extract Valid Data**
   - Extract valid half-bytes from each 6-byte block: `byte0.high, byte1.high, byte1.low, byte2.low, byte4.high, byte5.high`.
   - The tail block is extracted based on `len(plaintext) mod 3`.

4. **Recover Key Transformations**
   - The key `121` indicates a cyclic operation: `1, 2, 1, 1, 2, 1, ...`
   - For key=1: `(H,L) -> (L+4, H+5) mod 16` (swap + offset)
   - For key=2: `(H,L) -> (H+5, L+4) mod 16` (no swap + offset)
   - Inverse transformation for key=1: `L=(a-4)%16, H=(b-5)%16`; for key=2: `H=(a-5)%16, L=(b-4)%16`.

5. **Recover Position Reordering**
   - Encryption processes plaintext in 3-byte blocks from the right.
   - Full block: `ABC -> CAB` (right cyclic shift by 1)
   - Two-byte block: `AB -> BA`
   - Single byte: `A -> A`
   - Block order is output from right to left.
   - Decryption reverses the block order and performs a left cyclic shift by 1.

6. **Decrypt FLAG**
   - Extract valid half-bytes using fixed structure
   - Apply inverse half-byte transformations based on key cycle
   - Perform inverse position reordering to obtain final FLAG
