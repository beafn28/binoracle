# Skills CTF importados (ctf-pwn, ctf-reverse)

Contenido de la coleccion ctf-skills (MIT) ingerido en el RAG de binoracle para que la IA lo
consulte al detectar/auditar. NO se muestra en la biblioteca navegable (que se queda con los
cheat sheets curados de binoracle); solo alimenta la recuperacion del modelo.

- pwn/      : overflow, ROP, format-string, heap (tcache/FSOP/houses), kernel, sandbox escape,
              advanced-exploits (writeups reales), field-notes.
- reverse/  : tools (static/dynamic/emulation), anti-analysis, patterns (VMs, packers, ofuscacion),
              languages (Go/Rust/Python/.NET/WASM/Android), platforms (macOS/iOS/firmware/kernel).
