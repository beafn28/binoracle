# Default Values for Tools

- `js-reverse_list_network_requests`: First check the default results of the first page, and paginate if necessary.
- `js-reverse_search_in_sources`: Default is `excludeMinified=true`.
- `js-reverse_get_script_source`: Only read small snippets; prefer full source code with `js-reverse_save_script_source`.
- `js-reverse_break_on_xhr`: Only fill in URL fragments that can reliably hit the target.
- `js-reverse_get_paused_info`: Default is to check `frameIndex=0`.
