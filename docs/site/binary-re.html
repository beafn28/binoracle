Binary Reverse Engineering

Static readers for 15+ binary formats and 50+ execution-verified exploit families. Full REA parity. 100% offline.

Quick reference 
# Auto-detect format and analyze
binoracle identify ./binary

# Full exploit campaign: try all families, verify which work
binoracle autopwn ./challenge

# Single-shot ret2win with offset finding
binoracle autopoc ./challenge

# LLM-driven audit (Qwen 2.5 drives the agent loop)
binoracle audit ./challenge

# Specific formats
binoracle elf ./firmware.elf       # ELF: headers, mitigations, symbols
binoracle apk ./app.apk            # APK: manifest, DEX, signing
binoracle pe ./malware.exe         # PE: headers, imports, sections
binoracle dotnet ./assembly.dll    # .NET: metadata, CIL
binoracle wasm ./module.wasm       # WASM: WAT disassembly
binoracle js ./bundle.js           # JS: source recovery, imports

# ROP / gadgets
binoracle gadgets ./binary         # find ROP gadgets
binoracle rop ./binary             # build ROP chain
binoracle analyze ./binary         # chain analyzer + ROP arsenal

Static Readers

Static readers never execute the target binary. All analysis is deterministic and offline.

Area Formats What you get
Native ELF, Mach-O, PE/COFF, Go, WASM, core dumps Headers, mitigations (NX/PIE/RELRO/canary), symbols, sections, imports, ROP gadgets, mitigations summary
Mobile APK, DEX, AndroidManifest Manifest permissions, DEX classes/methods, signing certificate, native ABIs, JADX decompilation (optional)
Flutter / Dart AOT snapshots, libflutter.so, AssetManifest Snapshot hash/features, engine fingerprint, asset manifest (StandardMessageCodec)
Managed .NET/CLI assemblies (EXE, DLL) ECMA-335 metadata tables, CIL disassembly, type graph by token, managed/native boundary
Web / JS JS bundles, .asar (Electron), HAR Source map recovery, module imports, Electron app structure, HTTP archive analysis
Data SQLite, EVM, JAR/class, plist SQLite schema + queries, EVM opcodes/selectors, Java class structure, plist decode
Secrets Any binary Hardcoded secrets, API keys, certificates, IOCs — pattern-based + entropy analysis

Exploit Families

Every family is verified by executing a real shell in an isolated sandbox (no network, resource limits, ASLR off). Shell confirmation: unique marker echoed from the spawned shell. Samples in samples/src/*.c.

Stack / ROP / Control Flow

Family Mitigations handled Verification method
✓ ret2win (stripped, 32-bit) overflow + gift function Jumps to win() in sandbox, offset found symbolically or by scan
✓ ret2win on PIE NX + PIE Resolves PIE base (ASLR off), jumps to win()
✓ ret2libc with leak NX + ASLR (dynamic) Leaks puts@GOT, computes libc base, system('/bin/sh')
✓ ret2csu NX, gadget-poor no-PIE, x86-64 __libc_csu_init gadgets set rdi/rsi/rdx, indirect call
✓ ret2csu → execve NX, no pop rsi/rdx, x86-64 CSU sets rsi=0/rdx=0, pop rdi=&'/bin/sh', syscall → execve
✓ SROP x86-64 NX, gadget-poor no-PIE One sigreturn → forged register frame → execve
✓ SROP x86-32 NX, gadget-poor no-PIE Same via int 0x80 / pop eax gadget
⚠ SROP aarch64 NX, gadget-poor Degrades honestly if no aarch64 environment
✓ ret2dlresolve x64 NX, Partial RELRO, no libc leak Forges linker resolver structures → system('/bin/sh')
✓ ret2dlresolve 32-bit NX, Partial RELRO, no libc leak Same via 32-bit link_map / reloc structures
✓ format-string Partial RELRO NX + printf@GOT Overwrites printf@GOT with system → system('/bin/sh')
✓ format-string Full RELRO NX + PIE + Full RELRO GOT read-only → ret2system via printf saved return on stack
✓ stack canary bypass NX + stack canary Leaks canary via %s echo or format string, rewrites in-place
✓ stack pivot (migration) NX, short overflow saved RBP=&bss buffer, RIP=leave;ret → pivot to full chain
✓ write-what-where NX Unchecked index → GOT entry = win()

✓ shellcode NX off Inject x86-64 / x86-32 shellcode directly

ROP Arsenal

binoracle analyze ./binary produces a chain analyzer report with:

Gadget coverage

  • Best gadget per argument register (rdi/rsi/rdx/rcx/r8/r9/rax)
  • Syscall gadget
  • Least-noisy stack pivot
  • Write-what-where gadgets
  • Register-to-register move gadgets
  • execve-by-syscall coverage check

Chain detection

  • ret2csu universal gadgets
  • one_gadget magic offsets (statically-linked)
  • Heap chain analyzer: ExploitChain per applicable family
  • Automatic dispatch to verify_chain
  • HTML report with chain graph
