Tutorial de binoracle

Este tutorial recorre todas las capacidades de binoracle: desde la instalación inicial hasta ejecutar una investigación CVE completa y generar una cadena de exploit contra un binario local. Todo se ejecuta en tu máquina; no se requieren claves de API externas ni servicios en la nube.

Aviso legal — binoracle es una herramienta de investigación y educación. Todos los laboratorios CVE se ejecutan contra contenedores Docker que tú creas localmente. No la uses contra sistemas que no sean tuyos o para los que no tengas permiso escrito explícito.

1. Instalación

pip install binoracle
pip install binoracle[pwn]        # pwntools + ROPgadget
pip install binoracle[symbolic]   # ejecución simbólica angr
pip install binoracle[screenshots] # capturas Playwright
pip install binoracle[all]        # todo lo anterior

Verifica: binoracle --version

2. Configuración

curl -fsSL https://ollama.com/install.sh | sh
ollama pull qwen2.5-coder:7b

export BINORACLE_BACKEND=openai
export BINORACLE_BASE_URL=http://127.0.0.1:11434/v1
export BINORACLE_MODEL=qwen2.5-coder:7b
export BINORACLE_LANG=es

3. Motor CVE

El motor CVE toma un identificador CVE, recupera el descriptor de NVD, lo envía al LLM local, y genera y verifica de forma autónoma un proof-of-concept contra un laboratorio Docker efímero.

binoracle cve CVE-2025-27516
binoracle cve-batch CVE-2025-27516 CVE-2024-23334
binoracle cve CVE-2025-27516 --lang en
binoracle cve CVE-2025-27516 --out ./informes/
binoracle cve CVE-2025-27516 --open-report

Pasos del motor

PasoQué ocurre
1 — NVDRecupera identificador CVE, puntuación CVSS, versión afectada y descripción.
2 — Hipótesis LLMQwen 2.5 Coder genera hipótesis estructurada: clase de vulnerabilidad, endpoint, estrategia de payload, scaffolder.
3 — ScaffolderMapea el ecosistema a la plantilla Docker Compose correspondiente.
4 — Lab DockerLevanta lab efímero con paquete vulnerable fijado. Se destruye al terminar.
5 — PlaywrightEjecuta el PoC, captura pantallas en cada paso HTTP, escribe el informe HTML.

4. Motor de Reversing Binario

binoracle pwn ./binario           # cadena de exploit completa
binoracle triage ./binario        # mitigaciones, símbolos, importaciones
binoracle decompile ./binario     # decompilación multi-motor
binoracle rop ./binario           # búsqueda de gadgets ROP + síntesis
binoracle hardening ./binario     # evaluación de hardening

6. Informes

Cada investigación CVE genera un informe HTML con: resumen ejecutivo con puntuación CVSS, hipótesis del LLM con cadena de razonamiento, configuración del laboratorio, capturas de pantalla de Playwright, código PoC completo y recomendaciones de remediación.
