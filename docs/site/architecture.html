Key Design Decisions

Local-first LLM

The LLM (Qwen 2.5 Coder 7B) runs entirely on the researcher's machine via Ollama. This ensures zero data exfiltration, air-gap compatibility, and reproducible results regardless of cloud API changes.

Oracle-grounded analysis

Oracles provide deterministic, ground-truth facts (binary sections, mitigations, imports, symbols). The LLM's role is synthesis and hypothesis generation — never the source of binary facts. This eliminates hallucinated addresses or offsets.

Ephemeral Docker labs

Every CVE lab is a fresh Docker Compose stack created from scratch and destroyed after verification. No persistent vulnerable containers. No shared state between CVE runs. Playwright drives verification through the actual HTTP interface, not mocked responses.

Bilingual reports

All report templates support English and Spanish via a _lg(es, en) helper that emits both and uses CSS to show the selected language. Reports ship both languages embedded, so the reader can toggle without re-running the investigation.
