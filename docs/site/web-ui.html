Web UI

binoracle ships a full visual interface that exposes every CLI capability — no terminal needed. Launch it with:

binoracle web

Then open http://localhost:8000 in your browser. The server streams all output live via Server-Sent Events (SSE), so the page updates in real time as an investigation runs.

Starting the UI

terminal
# default: port 8000
binoracle web

# custom port
binoracle web --port 9090

Exploit Dev tab

The main tab. Enter a CVE ID (CVE-2024-1071) and pick a mode from the dropdown:

ModeCommandWhat it does
Dev Exploitbinoracle cveFull autonomous exploit development — spins up a Docker lab, generates PoC, verifies, exports report
Exploit Planbinoracle cveplanStructured exploitation plan from a CVE ID or description (no lab needed)

The phase progress bar tracks NVD lookup → LLM hypothesis → code analysis → lab → PoC → verify → report as the investigation runs. The CVSS badge, description, affected version, and PoC source link appear in the result panel.

Binary Lab tab

Drag and drop any binary file (ELF, PE, APK, Mach-O, WASM, JAR, .NET, Go, Rust, firmware, HAR, SQLite, EVM, JS, core dump) or use the Browse button. The file is uploaded to the server and auto-identified. Then pick a tool group:

GroupTools
Static Analysisidentify, elf, pe, macho, apk, java, wasm, dotnet, go, rust, firmware, har, sqlite, evm, asar, plist, js, rawshellcode, core, jeb
Analysissecrets, funcid, analyze, explain, audit, heap, triage, hunt
Exploitationgadgets, arsenal, rop, shellcode, fmtstring, primitives, autopoc, autopwn
Fuzzingfuzz, exploit-skeleton, cve-corpus
Utilitiescyclic (pattern generation), shellcode (arch), kernel-exploit (technique) — no file required, prompts for argument

All output streams live to the terminal below the tool buttons. The running button is highlighted in orange.

System tab

  • Environment Check — runs binoracle doctor: verifies LLM backend, all oracle modules, RAG knowledge base, and tool availability
  • MCP Server — config snippet for Claude Desktop, Continue, or any MCP client. Launch with binoracle mcp
  • Watch CVE Feed — instructions for running binoracle investigate-watch in a terminal to auto-investigate new CVEs from Telegram
  • Batch Investigation — enter CVE IDs separated by spaces, runs binoracle investigate-batch in parallel

Exploit Plan tab

Runs binoracle cveplan. Enter a CVE ID (CVE-2024-1071) or a plain-text description ("SQL injection in Ultimate Member") to get a structured exploitation plan including:

  • Vulnerability class and primitive
  • Phase-by-phase approach (recon, primitive, objective)
  • Pwntools skeleton when a binary is involved

For binary-specific questions, upload the file in Binary Lab and use the Explain or Audit buttons there.

All Tools catalog

A searchable grid of every CLI command. Use the search box to filter by name, description, or category. Click a card to jump to the right tab: CVE tools switch to Exploit Dev, binary tools switch to Binary Lab, Exploit Plan opens that tab.
