Web UI

A full visual interface for every binoracle capability — no terminal needed. Output streams live via Server-Sent Events as investigations run.

Starting the UI

# default port 8000
binoracle web

# custom port
binoracle web --port 9090

Then open http://localhost:8000. The page reconnects automatically if the server restarts.

Exploit Dev

Type a CVE ID (e.g. CVE-2024-1071) into the input bar and press Run. The engine runs the full autonomous pipeline:

 CVE ID input
   │
   ├── NVD lookup ────── CVSS score, description, affected version
   ├── LLM hypothesis ── vulnerability class, endpoint, payload
   ├── Code analysis ─── source download, sink/source tracing
   ├── Docker lab ─────── ephemeral WordPress / app container
   ├── PoC execution ──── Playwright screenshots at each step
   └── Report ──────────  CVSS badge, evidence, PDF export

The phase tracker shows progress across all stages. When the run finishes the Report tab populates automatically and the Export PDF button becomes active.

Export PDF

Click Export PDF in the top bar to download a complete A4 PDF of the report — dark theme, embedded screenshots, step-by-step evidence. No print dialog appears; the file saves directly.

Tip. The PDF is generated server-side by Playwright. It includes all screenshots that appear in the Report tab at the moment you click the button.

Binary Lab
